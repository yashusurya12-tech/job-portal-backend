# Job Portal Backend

A backend application for a job portal built using Node.js, Express.js and MongoDB.

## Features

- User registration and login
- User profile management
- Role-based access for job seekers, employers and admins
- Job creation, updating and deletion
- Job applications
- Application status management
- Admin user and job management

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Cookies
- Postman

## Main Collections

The application uses three main collections:

1. Users
2. Jobs
3. Applications

## User Roles

- Job Seeker
- Employer
- Admin
